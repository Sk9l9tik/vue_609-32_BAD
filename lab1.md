## Ответы на вопросы

1. Чтобы запустить приложение в режиме разработки

```bash 
npm install
npm run dev
```

2. суть императивного и декларативного стиля написания кода

В императивном стиле описывается пошаговый алгоритм, чтобы получить результат. В декларативном стиле указывается то что должно быть на выходе, а детали реализации скрыты слоем абстракции

3. Компонентный подход в VUE

Суть в разбиении ui на независимые переиспользуемые компоненты, каждый из которых содержит внутри себя разметку, логику и стилих

4. Реактивность

Реактивность - механизм, при котором изменение данных приводит к автоматическому обновлению всех элементов, что от него зависят без ручной перерисовки.
